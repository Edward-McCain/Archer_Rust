# Задача: Кроссплатформенный архиватор/разархиватор для macOS на Rust + Tauri

## Цель
Создать нативное macOS-приложение для создания и распаковки архивов
с современным, стильным пользовательским интерфейсом.

## Технологический стек
- **Backend**: Rust
- **Frontend/UI**: Tauri 2.x (HTML/CSS/JS или React + TypeScript)
- **Сборка**: cargo + tauri-cli
- **Целевая платформа**: macOS (Apple Silicon + Intel), нативная упаковка в .app и .dmg

## Поддерживаемые форматы архивов
- ZIP (чтение и запись) — крейт `zip`
- TAR, TAR.GZ, TAR.BZ2, TAR.XZ — крейты `tar`, `flate2`, `bzip2`, `xz2`
- 7Z (чтение и запись) — крейт `sevenz-rust`
- RAR (только распаковка, т.к. формат проприетарный) — крейт `unrar`
- GZIP / BZIP2 / XZ как отдельные файлы (не только внутри tar)

## Функциональность
1. **Распаковка архивов**:
   - Drag & drop файла архива в окно приложения
   - Автоопределение формата по расширению/сигнатуре файла
   - Выбор папки назначения
   - Прогресс-бар распаковки с отображением текущего файла
   - Поддержка паролей (для ZIP/7Z/RAR)

2. **Создание архивов**:
   - Drag & drop файлов/папок для добавления в архив
   - Выбор формата архива (ZIP, TAR.GZ, 7Z и т.д.)
   - Выбор уровня сжатия (быстро / баланс / максимальное сжатие)
   - Возможность установить пароль на архив (для ZIP/7Z)
   - Прогресс-бар создания архива

3. **Просмотр содержимого архива** без полной распаковки (список файлов, размеры, дата изменения)

4. **Извлечение отдельных файлов** из архива (без распаковки всего архива)

5. **История последних операций** (недавно открытые/созданные архивы)

## Требования к UI/UX
- Современный минималистичный дизайн в духе нативных macOS-приложений
  (учитывать Human Interface Guidelines Apple)
- Поддержка светлой и тёмной темы (авто-переключение по системным настройкам)
- Плавные анимации при drag & drop, прогресс-барах, переходах между экранами
- Кастомный титл-бар (vibrancy/blur эффект как у нативных приложений)
- Адаптивная иконка приложения и иконка в Dock
- Уведомления через нативный Notification Center по завершении операций
- Поддержка Quick Look / контекстного меню Finder (опционально, через
  Finder Sync Extension — обсудить целесообразность)

## Архитектура
- Разделить логику на:
  - `core/` — чистая Rust-библиотека с логикой архивации/разархивации
    (независима от UI, тестируема отдельно)
  - `src-tauri/` — Tauri backend, обёртка над core с командами (commands)
    для вызова из фронтенда
  - `src/` — фронтенд (UI)
- Все тяжёлые операции (упаковка/распаковка) выполнять в отдельном потоке/
  async-задаче, чтобы не блокировать UI
- Прогресс операций передавать во фронтенд через Tauri events

## Что нужно от тебя (Cursor)
1. Предложи структуру проекта (дерево папок и файлов)
2. Настрой Cargo.toml с нужными зависимостями и Tauri-конфигурацию
3. Реализуй core-модуль с функциями упаковки/распаковки для каждого формата
4. Реализуй Tauri-команды для вызова из фронтенда
5. Сделай красивый UI с drag & drop зоной, списком файлов, прогресс-баром
   и переключением тем
6. Добавь обработку ошибок (некорректный архив, неверный пароль, нет прав
   на запись и т.д.) с понятными пользователю сообщениями
7. Настрой сборку .app и .dmg для распространения
